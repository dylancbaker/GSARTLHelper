# Ground SAR Team Leader Course Helper

This tool is designed to help those teaching the GSARTL course via JIBC. It takes a list of students and instructors, then assigns everyone to scenarios.

It will prevent instructors from overseeing anyone on their own SAR group.  

For the second set of scenarios, it takes multiple passes to try and reduce the number of people who have the same instructor and/or the same people in their group.

If you would like to contribute, please create a branch or fork then submit a pull request.
